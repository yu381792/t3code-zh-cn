# T3 Code V2 中英双语桌面版

仓库仅维护 `main` 一个 V2 分支；旧分支与旧标签已备份后退出活动入口。

本分支基于官方 V2 主线 `fed41fa88bb27cb4325cb208d571393850bc63c2`，不是 V1 稳定版 v0.0.45。实际服务使用 `apps/server/src/orchestration-v2/` 和 `statev2.sqlite`。

Mac Apple Silicon 安装包中的应用名为 **T3 Code (Nightly)**，构建版本为 `0.0.46-nightly.20261003.2`（本 fork 的开发版编号，不是官方 0.0.46 稳定发布）。打开设置搜索“语言”，选择简体中文或 English。选择会持久保存，并即时切换界面与原生应用菜单。

这沿用原仓库的应用内语言层，不是外部 ASAR 覆盖补丁。现有语言设置优先；未设置语言时沿用原 fork 默认的 English，可在设置中切换中文。

V2 首次启动按官方逻辑复制 V1 数据库并迁移副本。V1/V2 后续对话不互相同步；设置、附件和工作区仍共享。原版迁移说明见 [官方 V2 迁移文档](docs/user/thread-migration.md)。不要清理用户数据目录；删除旧应用不应删除对话、项目设置和凭据。

本地 ad-hoc 签名不是 Apple Developer ID 签名或公证。首次被 macOS 拦截时，使用“系统设置 → 隐私与安全性 → 仍要打开”，不要关闭系统安全机制。中文版更新源配置到本 fork，尚未验证自动更新，不会主动切回官方英文稳定版。

仅覆盖 Web/Electron 桌面界面与应用原生菜单；独立移动端和第三方网页不在此次交付范围。
